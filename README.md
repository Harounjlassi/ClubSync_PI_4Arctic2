# 📋 Gestion Projet - Task Management System  

*A full-stack project management tool with task tracking, reporting, and team messaging.*  

![App Screenshot](screenshot.png)  

## 🌟 Features  
### **Task Management**  
- Create, assign, and track tasks with deadlines.  
- Filter tasks by status (To-Do, In Progress, Done).  
- Priority labels (High/Medium/Low).  

### **Reporting**  
- Generate PDF/Excel reports on project progress.  
- Dashboard with task completion analytics.  
- Team performance metrics.  

### **Messaging**  
- chat for team discussions.  
- Notifications for task updates.  
- Comment threads on tasks.  

---

## 🛠️ Tech Stack  
**Frontend**:  
- Angular 15+  
- PrimeNG (UI Components)  
- Chart.js (Analytics Dashboards)  

**Backend**:  
- Spring Boot 3.x  
- Spring Security (JWT Authentication)  
- Spring Data JPA (PostgreSQL)  
- WebSocket (Real-time messaging)  

**Other**:  
- JasperReports (PDF generation)  
- Docker (Containerization)
